📲 How to Install an App

Tap INSTALL / OPEN above first. The app's installer page will open in your browser.

  1. Make sure the installer page opens in the actual Chrome app.
  2. Tap Chrome's three-dot menu.
  3. Tap Add page to.
  4. Choose Install as web app.
  5. Confirm the installation.
  6. Open the new app from your Home screen or Apps screen.
  1. Open the installer page in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen.
  4. If your device shows Open as Web App, leave it enabled.
  5. Tap Add.
  6. Open the new app from your Home Screen.
Important: Install from the dedicated installer page. If you see a gray Google "G" icon or Create shortcut, cancel — you're on the wrong page.
Manager apps: Installing Order Prep or Manager Hub does not bypass their manager access controls.
